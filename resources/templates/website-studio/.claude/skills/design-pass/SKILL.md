---
name: design-pass
description: Polish a page's visual design — spacing, hierarchy, color, type — editing the page and the shared stylesheet.
---

Do a design pass on the focused page:

1. Read the page and `assets/site.css`.
2. Judge it like a designer: type scale and rhythm, spacing consistency,
   alignment, color contrast (WCAG AA at minimum), hierarchy — does the eye
   land where it should?
3. Fix what you find. Shared improvements go in `assets/site.css`; only
   page-specific structure changes go in the page itself.
4. Do not add frameworks, external fonts, or CDN links. Work with system
   font stacks and hand-written CSS.
5. Reply with a short list of what changed and why — one line each.
